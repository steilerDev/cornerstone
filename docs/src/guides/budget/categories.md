# Cost Categories

Cost categories organize your construction costs into logical groups. Every cost line on a work item must belong to a category, making it easy to see how much you're spending on each part of your project.

:::info Moved to Project setup
Cost categories used to be under **Budget > Categories**. That address now opens **Settings > Project setup** at the **Cost categories** section, so old links and bookmarks still work.
:::

## Common Categories

Typical categories for a home building project might include:

- Electrical
- Plumbing
- Windows & Doors
- Flooring
- Roofing
- HVAC
- Landscaping
- Permits & Fees

You can create whatever categories make sense for your project.

## Where to Find Them

Cost categories are kept in **Settings > Project setup**. Purchase categories (for [household items](/guides/household-items)) and photo orientations are listed on the same page, each in its own section.

## Creating a Cost Category

Navigate to **Settings > Project setup** and find the **Cost categories** section. Select **New cost category** and provide:

- **Name** -- A short label (e.g., "Electrical")
- **Description** -- Optional details about what costs belong in this category
- **Color** -- Optional. Pick a color to tell categories apart at a glance, or choose **No color**

## Searching and Reordering

A section with 8 or more entries shows a **Search cost categories** field above the list. Type part of a name to narrow the list. If nothing matches, the list says *No cost categories match.* with a **Clear search** button.

While a search is on, reordering is turned off. Clear the search to reorder the list. The section heading shows how many entries it holds, for example **Cost categories (12)**.

To reorder a list, drag a row by its reorder handle, or open the row's actions menu and choose **Move up** or **Move down**. With a keyboard, focus the handle, press Space to pick the row up, use the arrow keys to move it, and press Space again to drop it. Press Escape to cancel.

## Managing Cost Categories

From the **Cost categories** section you can:

- **Edit** a category's name, description, or color
- **Delete** a category that is no longer needed

:::caution
Deleting a cost category will fail if cost lines or grants still use it. Reassign or remove those cost lines first.
:::

## Purchase Categories

Purchase categories work the same way. They are listed in the **Purchase categories** section of **Settings > Project setup** and group your household purchases by type.

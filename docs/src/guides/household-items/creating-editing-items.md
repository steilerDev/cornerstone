# Creating & Editing Items

## Creating a Purchase

Navigate to **Purchases** in the main navigation and click **New purchase**. The create form collects:

- **Name** (required) -- A descriptive name for the purchase (e.g., "Kitchen island pendant lights")
- **Purchase Status** -- Planned, Ordered, Delivery scheduled, or Delivered (defaults to Planned)
- **Description** -- Optional longer description or notes about the purchase
- **Room** -- Optional room or location where the item will be placed (e.g., "Kitchen", "Master bedroom")
- **Quantity** -- Number of units (defaults to 1)
- **Vendor** -- Optional company or retailer for this purchase
- **URL** -- Optional product link for reference
- **Order Date** -- When the purchase was or will be ordered
- **Earliest Delivery** -- Start of the expected delivery window
- **Latest Delivery** -- End of the expected delivery window
- **Category** -- The purchase category, such as Furniture or Appliances (defaults to Other). Type to search, or choose **New category ‹text›** to create one. A small dialog asks only for the name
- **Area** -- Optional location within your project (e.g., "Kitchen", "Master Bedroom")

Click **Create** to save the new purchase. You will be taken to the purchase's detail page where you can add budget lines, notes, dependencies, and more.

## Editing a Purchase

There are two ways to edit a purchase:

### Inline Editing

On the detail page, click any editable field to modify it directly. Changes are saved automatically when you click away or press Enter.

### Edit Page

Click the **Edit** button on the detail page to open the full edit form. This is useful when you want to update multiple fields at once.

## Notes

Add timestamped notes to any purchase from the detail page. Notes show the author and creation time, and are displayed newest-first.

Click **Add Note** to expand the note editor, type your note, and click **Save**.

:::caution
Deleting a note is permanent and cannot be undone.
:::

## Areas

Purchases share the same area system as tasks. Type in the **Area** field to search. Results show the full path, such as *Ground floor › Kitchen*, so you can quickly find the right location. If no area matches, choose **New area ‹text›** to create it and select it.

## Deleting a Purchase

On the detail page, click the **Delete** button. A confirmation dialog will appear before the item is permanently removed.

:::caution
Deleting a purchase also removes all associated budget lines, notes, dependencies, grant links, and document links. This action cannot be undone.
:::
